# Key index — what flows between weavers

_Generated by `make index` (`weaverkit index`) — do not edit by hand._

The inverse of [`weavers-index.tsv`](weavers-index.tsv): a row per **key**, showing which weaver produces it and which consume it. Key names and descriptions come from `weaverkit/src/weaverkit/keys.py`.
