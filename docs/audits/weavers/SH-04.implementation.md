## Design decisions

The shared core lookup/resolver mappers, and NCBI's custom taxon mapper, report no
computed groups on `ERROR`. Existing executor error results remain uncached.
Valid completed misses retain their existing group semantics. No new cache or
resume machinery was added; the regression tests exercise the existing memory
and SQLite caches.

Source-specific coverage remains in the source adapters. NCBI uses a private page
traversal guard reused by seven report collectors. Wikipedia uses shared pure
measurement/window helpers across its adapters. AGORA persists model acquisition
outcomes alongside reaction membership; GMrepo persists a JSON acquisition manifest
alongside normalized tables. These changes use existing dispatch, mapping,
source-binding and atomic database build mechanisms rather than a new hierarchy.

## Interface and migration details

- UniProt outbound targets each have their own group. Mapping count/records fetch
  all twelve supported targets, including when combined with one target request.
  Counts represent returned mappings, not distinct biological entities. A failed
  target job fails the summary. Target-only requests retain their small job scope.
- STRING adds `protein.interaction.coverage` to its summary group and emits a scope
  warning. The count describes observed edges; fan-out covers retrieved partner
  names. Completeness is unknown even when fewer than the configured limit return.
  The retrieval limit participates in the backend fingerprint.
- NCBI adds `gene.product.coverage` and `genome.sequence.coverage` to their existing
  enrichment groups. Products paginate, and products/sequences return all acquired
  records instead of silently stopping at 200. List display records remain capped
  at 200 with full identifiers and true counts. Report traversal defaults to 1,000
  pages, configurable on `DatasetsV2Backend`; cycles/budget exhaustion and unavailable
  continuation pages fail closed with incomplete acquisition details.
- BacDive builders both default to 1,000 strains and honor supplied scan budgets.
  Requests fetch only the remaining budget. Exhausting the complete catalog is a
  miss; reaching the budget with remaining work, missing fetched strains or broken
  continuation pages is an error. Traits describe one selected type strain.
- AGORA reaction database schema 2 includes `model_coverage` and processed/skipped
  counts. Parse failures or XML without an SBML model are persisted as skipped.
  Missing/skipped reconstructions cannot appear as known empty repertoires. Old
  databases require rebuilding. Core-only crosswalk queries remain available;
  explicitly requested unavailable reactions/SBML fail, including partially
  available multi-model requests. Download consent behavior is preserved.
- GMrepo database schema 2 requires `meta.acquisition`; old databases require
  rebuilding. Per-taxon failures cannot become zero associations. Profile results
  distinguish requested/selected/fetched/empty/failed runs and capped acquisition.
  `n_runs` remains the number of runs with rows, also named `n_runs_with_rows`;
  `denominator.fetched_runs` includes successful empty profiles, and
  `denominator.cohort_total_runs` is the catalog size when available. Successful
  empty acquisition is represented explicitly; unacquired profiles are unavailable.
  Caller-supplied tables without outcomes expose unknown completeness.
- Wikipedia adds `wikipedia.pageviews.measurement` and optional `months`,
  `end_month` and `agent` parameters. API defaults are twelve completed months of
  all-agent views; local defaults are one stored month of user views. Both expose
  those defaults and support comparable explicitly requested scopes or return an
  unsupported-scope error. Duplicate/unrequested bins and mismatched response
  measurements fail; missing bins expose an incomplete observed subtotal, and no
  acquired bins is an error. Local dump parser completeness remains unknown.

Core is patch-bumped to 0.21.1. All seven changed weavers are patch-bumped in their
three version sites and require core >=0.21.1. Weaverkit is patch-bumped to 0.6.4
for the five added output-catalog descriptions; the lockfile and generated key,
weaver and network documentation are refreshed. No contract tests were weakened.
Existing non-contract tests asserting misleading misses/omissions or the old
literal NCBI fingerprint were deliberately updated to the new semantics.

## Verification

- Full workspace: 1,753 pytest passes, 50 expected offline skips, plus 5 release-tool
  unittest passes. Lint and whitespace checks pass.
- All seven changed weavers pass strict verification, including offline goldens.
- Live API checks: UniProt 8, STRING 2, BacDive 2, NCBI 5 API-only, Wikipedia 1;
  18 passed. NCBI's database-download tests were deselected.
- Regression tests cover both cache implementations and both UniProt target request
  orders, summary-only mappings, uncached failed NCBI enrichment, pagination cycles
  and budgets, acquisition beyond 200 records, exact BacDive scan exhaustion,
  AGORA processed/empty/skipped models, GMrepo failed/empty/capped outcomes and
  cohort denominators, and Wikipedia year boundaries/duplicate/missing bins and
  unsupported local measurement scope.

AGORA and GMrepo were tested with tiny generated local artifacts and mocked
acquisition responses. No multi-GB archive or full GMrepo crawl was downloaded.
Local tooling remains isolated in `.audit-local/tools/venv`.
