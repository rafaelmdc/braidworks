## Design boundaries

The domain-neutral core receives only `remote_fingerprint(namespace, endpoint,
**settings)`: deterministic JSON hashing of an effective endpoint and semantic
settings, without returning endpoint credentials. Source-specific policy stays in
weavers. Display caps remain immutable backend policy exposed through builders;
no new per-query limit parameters or capabilities were introduced.

An injected HTTP client's base URL is the effective endpoint. Remote fingerprints
identify configuration; PDBe/QuickGO/Reactome remain unversioned live sources,
not immutable snapshots. STRING's default uses a provider-published stable release
address. Custom/unversioned STRING endpoints retain an explicit unknown-release
scope instead of claiming the default release.

All local backends retain existing `SourceBinding` generation checks; metadata and
lookup rows share the bound read transaction. No persistent cache/resume mechanism
or generic database abstraction was introduced.

GTDB's source-local release module composes small manifest fetches, resource hash
verification and the existing download/staged-publication mechanics. An official
crosswalk records the checksum manifest for metadata and trees; automatic tree
selection uses that stored bundle, not another query to mutable latest. The backend
checks supplied trees against the official bundle when tree placement is requested.
Custom or legacy resources can be supplied explicitly, without a claim of verified
official coherence. Temporary metadata archives are cleaned on failure as well as
success; rows feed the existing crosswalk builder through an iterator.

MONDO uses the standard-library topological sorter for DAG validation. Its default
OBO acquisition remains the current provider artifact; `expected_version` checks
its actual header, rather than selecting an archive or relabelling content. A
missing version is an explicitly unversioned SHA-256 identity. Caller-supplied term
fixtures record normalized term content rather than claiming an original OBO hash.

Wikipedia hashes consumed compressed bytes during decompression. Text fixtures use
a separately labelled hash with explicit line boundaries. Coverage counts relevant
valid/invalid rows and irrelevant rows. Malformed or negative relevant rows are
excluded and diagnosed; valid zero rows remain known zero. Invalid UTF-8 and corrupt
compression fail the build. Completeness describes parsing the supplied artifact,
not the quality/completeness of upstream traffic collection. Missing articles under
partial parsing return an availability error; retained totals report incomplete
coverage.

## Configuration and migration

- PDBe: `build_pdbe_weaver(base_url=..., client=..., limit=25)`.
- QuickGO: `build_quickgo_weaver(base_url=..., client=..., max_pages=10)`.
- Reactome: `build_reactome_weaver(base_url=..., client=..., limit=30)`.
- STRING: `build_string_weaver(base_url=..., client=..., limit=25)`; default
  `https://version-12-5.string-db.org/api`. Changed fingerprints invalidate old
  source-policy cache entries. Settings must be positive integers, not booleans.
- GTDB: public builder/setup accepts `release="R232"`; defaults pin new acquisition
  to R232. Existing crosswalks remain usable for taxonomy. Refresh legacy databases
  before verified automatic tree acquisition; custom/legacy sources need explicit
  matching local tree paths. Custom metadata URLs must be supplied together.
  Official-labelled custom tree URL acquisition is rejected; prepare local files.
- MONDO: `expected_version="releases/YYYY-MM-DD"` checks a known header value;
  schema 1 requires rebuild for schema 2 provenance/validation. No archive-selection
  API is claimed. Missing header versions remain explicitly unversioned content.
- Wikipedia: schema 1 requires rebuilding. Existing valid prebuilt paths infer
  their month; explicit month conflicts require another path or `refresh=True`.
  A partial parse now exposes incomplete measurement and cannot claim absence.
- No capability IDs/output-key additions. Existing Wikipedia measurement
  completeness becomes observed True/False rather than unknown for new dumps.
- Versions: core 0.21.3; PDBe/QuickGO/Reactome 0.1.10; STRING 0.1.9;
  GTDB 0.2.5; MONDO 0.2.3; Wikipedia 0.1.6. Four remote sources require core
  >=0.21.3; all weaver version sites regenerated from their specifications.
