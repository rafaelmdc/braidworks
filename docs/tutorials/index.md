# Tutorials

Lessons that teach Braidworks by doing one complete, real example. Start with the
browser or with Python; each lesson says what it needs and what you will have at the
end.

| Lesson | What you will produce |
|---|---|
| [Your first query in the browser](first-query-in-the-browser.md) | Names, structures and pathways for two genes, with the route that answered and a CSV, without code |
| [Your first analysis in Python](first-analysis-in-python.md) | The same kind of lookup as a pandas table with citations |
| [Find experimental structures for a protein list](protein-structures.md) | A structure listing, two inspected entries and a batch export |
| [Trace a microbial functional annotation](microbial-functions.md) | An ecological annotation with the rule that supports it |
| [Inspect a disease–microbe association](disease-associations.md) | Observations with sample context and publications |

Runnable notebooks: the [getting-started notebook](../../notebooks/getting-started.ipynb)
(Colab or Jupyter) and three timed [case studies](../../notebooks/case-studies/README.md).
