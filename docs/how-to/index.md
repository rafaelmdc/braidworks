# How-to guides

Steps for a task you already have in mind. Each guide assumes Braidworks is
[installed](install.md).

| Task | Guide |
|---|---|
| Install Braidworks | [Install](install.md) |
| Look up fields for an ID from the command line | [Run a query](run-queries.md) |
| Look up many IDs, or a table | [Process a batch](process-a-batch.md) |
| Use Braidworks in a script or notebook | [Work in Python](work-in-python.md) |
| Use the browser interface | [Use the browser](use-the-browser.md) |
| Find a field's name | [Find a field](find-a-field.md) |
| Follow every structure, pathway or ortholog | [Follow related entities](follow-related-entities.md) |
| Check coverage and export results | [Check results](check-results.md) |
| Choose sources and prepare local data | [Choose and set up sources](choose-sources.md) |
| Prepare the local NCBI taxonomy | [NCBI database setup](set-up-ncbi-database.md) |
| Reuse lookups and continue saved work | [Cache and saved runs](cache-and-resume.md) |
| Limit requests to upstream services | [Set request rates](set-request-rates.md) |
| Show Braidworks without a network | [Run the offline demo](run-the-offline-demo.md) |
